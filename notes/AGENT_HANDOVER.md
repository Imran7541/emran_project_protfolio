The Emran Hosen portfolio features an executive Clean Extensionless URL Architecture (`/`, `/gallery`, `/contact`) across GitHub Pages, Coolify, and local Node.js server (port 5225). All internal navigation links have been converted to extensionless routes, legacy `.html` requests are permanently redirected via HTTP 301, and an in-head canonicalizer (`history.replaceState`) ensures the browser address bar remains clean with zero `.html` extensions. A smart `404.html` reconciles trailing slashes seamlessly. The site is live on GitHub Pages (`https://imran7541.github.io/emran_project_protfolio/` and `/gallery`), Coolify (`http://portfolio.127.0.0.1.sslip.io/gallery`), and local daemon (`node server.js`).
